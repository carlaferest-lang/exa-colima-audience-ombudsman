# Exa Colima Audience Ombudsman

Create a modern, clean, and highly professional corporate web application for an independent media ombudsman service titled "Defensoría Radio - Tus Derechos como Audiencia" (currently serving EXA FM 99.7 Colima, with a scalable multi-channel structure for future clients).



Design & Aesthetic:

- Color Palette: Deep authoritative blue primary, clean slate gray for text, crisp white background, and subtle warm neutral accents (like soft nude/greige) for cards.

- Typography: Clean sans-serif, highly legible, professional yet approachable.

- Layout: Modern SaaS / institutional landing page style with smooth scrolling, clear visual hierarchy, and distinct sections.



Required Sections & Components:

1. Navigation Bar: Logo ("Defensoría Radio"), links to "Inicio", "¿Qué es la Defensoría?", "Derechos de la Audiencia", "Código de Ética", and a prominent "Presentar una Queja / Contacto" button.

2. Hero Section: Catchy and trustworthy headline ("Tu voz en la radio, escuchada y defendida"), subtitle explaining the audience defender role for EXA FM 99.7 Colima, and direct CTA buttons to read the code of ethics or submit a report.

3. Interactive "Derechos de la Audiencia" Grid: Cards or an interactive accordion detailing key audience rights (Veracidad, Distinción de publicidad, Réplica, Protección a menores, No discriminación) with icons and short explanatory texts.

4. Código de Ética Section: A dedicated viewer area or clean card layout presenting the regulatory code of ethics, complete with a download button simulation.

5. Interactive Report / Contact Form ("Buzón de la Audiencia"): A functional form allowing listeners to submit feedback, suggestions, or formal complaints regarding broadcasts (Fields: Name, Email/Phone, Station/Frequency, Broadcast Date/Time, Type of Request dropdown [Queja, Sugerencia, Consulta], and Message textarea).

6. Multi-channel Scalability Notice / Footer: A professional footer indicating independence, legal compliance framework, copyright, and a subtle note indicating readiness to advise other broadcasting stations.



Ensure the UI is fully responsive, uses Tailwind CSS, and incorporates smooth hover states and clean card containers.
